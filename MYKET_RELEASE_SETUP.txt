نسخه اصلاح‌شده برای GitHub Actions و ساخت APK Release.

Workflow:
- بدون gradlew کار می‌کند.
- Gradle 8.7 را مستقیم نصب می‌کند.
- مسیر Keystore را درست استفاده می‌کند.
- Base64 خام یا خروجی certutil را می‌تواند Decode کند.
- APK نهایی را به صورت Artifact با نام myket-release-apk آپلود می‌کند.

Secrets مورد نیاز:
RELEASE_KEYSTORE_B64
RELEASE_STORE_PASSWORD
RELEASE_KEY_ALIAS
RELEASE_KEY_PASSWORD
